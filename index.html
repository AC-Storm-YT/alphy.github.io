Safe & External Management

Alphy operates completely outside of game memory, ensuring zero injection and maximum safety. Simply select your mods, and the app instantly secures your original game files with automated backups before any changes take place. One click to apply, one click to restore.

How it Works

1

Select Game Folder

When you run Alphy for the first time, you will be prompted to select your Rocket League installation folder. This target folder must be named rocketleague. For example: D:\EG\rocketleague.

2

Import a Mod

Click the Import new mod button. Use the file selector at the bottom right to choose your .upk mod file. Enter the name of your mod (e.g., Porsche 911 GT3 RS), type the item it replaces (e.g., Hotshot), and select the correct category (e.g., Body). Finally, click Add mod.

3

Select & Apply Mods

Click the three horizontal lines at the top left to change categories. Select the mods you want to equip, then click the save button at the bottom right. Alphy will automatically back up your original game files and apply the changes before you launch the game!

4

Remove Mods

To uninstall, click the Remove mods button. Select a category from the dropdown menu to view your installed mods. You can select a single mod, multiple mods, or all of them at once. Click Remove selected to instantly restore your original game files.

Alternative: Manual Installation

1

The Mods Directory

If you prefer not to use the UI, Alphy automatically generates a mods folder in the exact same location as the .exe file. Inside, you will find categorized sub-folders ready for your files:

Antenna
Banner
Body
Boost
Boost Audio
Decal
Goal Explosion
Hat
Trail
Wheels
2

Adding a Mod Manually

To install a new mod manually, navigate to the correct category, create a named folder for your mod, and drop the .upk file inside.

For example, if you want to replace the Octane body with a Fennec mod:
mods\Body\Fennec (Replaces Octane)\Body_Octane_SF.upk

3

Automatic Backup

Restart or launch Alphy. The app will immediately detect the new manual mod files. When you apply them, it safely copies your original game file to:
%appdata%\Alphy\Backups\Body_Octane_SF.upk.bak

Q&A

1. What is Alphy?

Alphy is a free, external mod manager built for Rocket League. It lets you easily apply custom cosmetics—like car bodies, decals, and goal explosions—by managing your local game files. It handles all the technical work for you, instantly swapping mods in and out while keeping your original game files safely backed up.

2. Is Alphy safe to use?

Yes. The mods loaded by Alphy are created using RLUPKTools, a utility that edits Unreal Engine Package (.upk) files. This means Alphy operates as a straightforward file manager. Instead of injecting code into your computer's memory while the game is running, Alphy simply swaps cosmetic assets—like 3D models and textures—on your hard drive before you even launch the game. Because it performs local file replacements rather than active memory editing, it does not trigger anti-cheat software.

Disclaimer: Users modify their game at their own risk. While this method has proven safe so far, we cannot be held responsible for any potential account bans in the future.

3. Is Alphy free?

Yes, it is completely free and will never become paid software. We also do not accept donations, as the app requires files from another source to be useful, and we feel it wouldn't be right to accept money for it.

4. Does Alphy work on console?

No. Alphy requires access to PC game directories and local files, meaning it is only available for Windows.

5. Does Alphy come with pre-installed mods?

No. Alphy is strictly a mod manager. We do not distribute or host any proprietary game assets or `.upk` files within the application. You must acquire the cosmetic files yourself and use Alphy to apply them to your game.

6. Where can I find mods to install?

Since Alphy does not include mods, you can find custom cosmetics created by the community in dedicated modding Discord servers, such as TitleWave Beta the official server.

7. Can other players see my mods?

No. Because Alphy modifies local `.upk` files on your hard drive, the custom cosmetics are client-side only. Other players will see the default vanilla car you have equipped.

8. Does it make automatic backups?

Always. The moment you apply a mod, Alphy clones your original game files into a secure vault in your AppData folder. You can revert to a clean, vanilla installation instantly through the app interface without ever touching your game folders manually.

9. How does version locking work?

To prevent game crashes after a Rocket League update, Alphy cross-references your game version with our supported version. If a mismatch is detected, the app locks modding features until we verify compatibility.
