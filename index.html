Safe & External Management

Alphy operates completely outside of game memory, ensuring zero injection and maximum safety. Simply select your mods, and the app instantly secures your original game files with automated backups before any changes take place. One click to apply, one click to restore.

How it Works

1

Select Game Folder

When you run Alphy for the first time, you will be prompted to select your Rocket League installation folder. This target folder must be named rocketleague. For example: D:\EG\rocketleague.

2

The Mods Directory

Once you run the application, it will automatically generate a mods folder in the exact same location as the Alphy .exe file. Inside, you will find categorized sub-folders ready for your files:

Antenna
Banner
Body
Boost
Boost Audio
Decal
Goal Explosion
Hat
Trail
Wheels
3

Adding a Mod

To install a new mod, navigate to the correct category, create a named folder for your mod, and drop the .upk file inside.

For example, if you want to replace the Octane body with a Fennec mod:

mods\Body\Fennec (Replaces Octane)\Body_Octane_SF.upk

4

Automatic Backup & Launch

Restart or launch Alphy. The app will immediately detect the new mod file and identify which vanilla game file needs to be replaced. Before making any changes, it safely copies your original game file to:

%appdata%\Alphy\Backups\Body_Octane_SF.upk.bak

Once the backup is secured, Alphy applies the mod and you are ready to play!

Q&A

Is Alphy safe to use?

Yes. The mods loaded by Alphy are created using RLUPKTools, a utility that edits Unreal Engine Package (.upk) files. This means Alphy operates as a straightforward file manager. Instead of injecting code into your computer's memory while the game is running, Alphy simply swaps cosmetic assets—like 3D models and textures—on your hard drive before you even launch the game. Because it performs local file replacements rather than active memory editing, it does not trigger anti-cheat software.

Does it make automatic backups?

Always. The moment you apply a mod, Alphy clones your original game files into a secure vault in your AppData folder. You can revert to a clean, vanilla installation instantly through the app interface without ever touching your game folders manually.

How does version locking work?

To prevent game crashes after a Rocket League update, Alphy cross-references your game version with our live database. If a mismatch is detected, the app locks modding features until we verify compatibility.
