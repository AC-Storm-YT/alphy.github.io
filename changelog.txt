-------------------------------------------

v1.5.0 - The Interface Overhaul - May 26 2026
-------------------------------------------
- Master-Detail UI: Replaced the old tabbed layout with a persistent, emoji-categorized sidebar and a dynamic, infinitely scalable mod grid.
- Real-Time Search: Added a top-mounted search bar to instantly filter and find specific mods across all categories.
- Smart Mod Removal: The mod deletion tool has been heavily upgraded. It now intelligently restores your original vanilla game files and cleans up orphaned backup files automatically to prevent ghost files.
- Dynamic Gradient Background: Replaced the static background image with a lightweight, programmatic CSS-style gradient that scales perfectly without using extra memory or pixelating.

v1.4.0 - The Visual Update - May 23 2026
-------------------------------------------
- Visual Mod Previews: Alphy now features a fully visual interface! For the very first time, you can see high-quality icons and previews of your mods directly in the app.
- Dynamic Cloud Icons: To keep the app size incredibly small, mod images are not bundled with the application. Alphy automatically downloads them directly from our cloud server and caches them locally.
- Self-Healing Image System: The application intelligently detects if a cached image is corrupted, improperly formatted, or missing. It will automatically repair itself by fetching a fresh copy in the background.
- Remote Updates: New mod icons can be added to the database remotely. They will appear instantly in your app without requiring you to download a new Alphy update.

v1.3.3 - Safety Update - May 16 2026
-------------------------------------------
- Build Tracking: Alphy now features a new build tracking system that cross-references the live Rocket League build against our supported build list via github.
- Enhanced Lockdown Protocol: If an unexpected Rocket League patch drops, Alphy will detect the build mismatch and lock the app.

v1.3.2 - Dynamic Backup Synchronization - May 11 2026

v1.3.0 - The Import & Removal Update - May 10 2026
-------------------------------------------
- Built-in Mod Importer: Added a brand new wizard to import mods directly into Alphy. Users can now select their downloaded files (supports both .upk and .bnk), pick a category, and specify what item it replaces. Alphy automatically builds the correct folder structure in the background.
- Dedicated Mod Removal Tool: Added a safe and easy way to permanently delete mods without ever opening Windows File Explorer. Includes category filtering and a convenient "Select All" toggle for mass deletion.
- Dashboard UI Update: Reorganized the main interface to seamlessly accommodate the new "Import New Mod" and "Remove Mods" tools alongside the existing save and update features.

-------------------------------------------
- New Navigation Drawer: Replaced the standard tabs with a sleek, modern side-drawer for much easier navigation across all categories.
- Fixed File Collisions: Implemented a "Two-Phase Save System" that prevents mods from accidentally overwriting each other when swapping between items that share the same base game file (e.g., Tunica and Dieci).

v1.2.0 - The Integrity & Sync Update - May 10 2026
-------------------------------------------
- Added 1 dedicated mod category: Paint.
- Implemented MD5 hashing to verify file integrity. The app now compares game files, mods, and backups to ensure original game files are never accidentally overwritten by modded versions.
- Active mods are now "sealed" with unique digital fingerprints in your settings. If the game launcher resets your files during an update, Alphy detects the change and automatically disables affected mods to prevent game crashes.
- Added logic to detect Rocket League version changes. The app automatically synchronizes and updates your vanilla backups when a patch is detected, ensuring a fresh "return to vanilla" point.
- Redesigned the startup validation process into a non-blocking background task, significantly reducing launch hangs and improving UI responsiveness.
